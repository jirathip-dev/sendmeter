# sendmeter rules (impl and rev briefs carry these; each names its enforcer)
- Don't let a Swift warning through: the three packages build with `-warnings-as-errors` under GATEKEEPER_STRICT=1, the app and watch builds with warnings as errors (enforced by: gatekeeper swift/warnings, local/app, local/watch)
- Don't force unwrap, `try!`, `as!`, `T!` or `fatalError` in Swift without a `// SAFETY:` line right above (enforced by: gatekeeper swift/anti-slop)
- Don't comment Swift (tests included) except `// SAFETY:` above a forced operation (enforced by: gatekeeper swift/anti-slop no-comments)
- Don't use `Any` or `AnyObject` as a Swift type (enforced by: gatekeeper swift/anti-slop no-any and the shared Any rules)
- Don't leave Swift imports unsorted (enforced by: gatekeeper swift/anti-slop sorted-imports)
- Don't leave a Swift declaration without its access level (enforced by: gatekeeper swift/anti-slop explicit-access)
- Don't swallow an error with an empty `catch` (enforced by: gatekeeper swift/anti-slop no-swallowed-errors)
- Don't put a raw colour or size in a view: take it from DesignSystem.swift or ChartTheme.swift (enforced by: gatekeeper swift/tokens)
- Don't grow a gatekeeper baseline: a listed finding may only be fixed and removed (enforced by: gatekeeper's stale check, CI arch-check frozen `.gatekeeper/baseline/`)
- Don't import SwiftUI, UIKit, Supabase, HealthKit, CoreBluetooth or WatchConnectivity across the Core, Data, Platform and pure-package boundaries in .drover/arch.toml (enforced by: CI arch-check bans)
- Don't read `Calendar.current`: use the Gregorian DateSupport helpers (enforced by: CI arch-check `Calendar.current` ban)
- Don't hold a refresh token on the watch or sign it in itself (enforced by: CI arch-check `refreshToken` ban)
- Don't add a line to AppModel.swift: the current app is frozen (enforced by: CI arch-check frozen list)
- Don't commit or hand-edit SendmeterNative.xcodeproj: project.yml is its source (enforced by: gatekeeper local/app (scripts/xcodegen.sh, scripts/assert-native-watch-project.rb))
- Don't hand-edit .claude/skills/gatekeeper: `./.gatekeeper/run skill` writes it (enforced by: CI arch-check generated files)
- Don't drop a pure package under its coverage floor in docs/testing.md (enforced by: gatekeeper local/coverage)
- Don't break the app-target, UI smoke or watch test suites (enforced by: gatekeeper local/app, local/watch)
- Don't name a retired command, recipe, workflow or script in the current docs (enforced by: gatekeeper local/docs)
- Don't add a dependency without the owner's OK and a reason in .gatekeeper/deps.toml (enforced by: gatekeeper core/deps)
- Don't grow the counted lines over ci/cap.toml (enforced by: gatekeeper core/cap)
- Don't edit the gatekeeper pin, wrapper or workflow call by hand: `./.gatekeeper/run pin <version>` (enforced by: gatekeeper core/pin)
- Don't push a PR body without `## For humans`, with a "Generated with" line, or naming no head sha (enforced by: gatekeeper core/pr-body)
- Don't commit a private name (enforced by: gatekeeper core/hygiene)
- Don't commit a secret (enforced by: secret-scan.yml gitleaks, gatekeeper swift/anti-slop no-hardcoded-secrets)
