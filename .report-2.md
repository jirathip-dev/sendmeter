### What the test asserts

For both `short` and `long` fixtures, `testTappingDismissRemoves{Short,Long}ErrorBanner`
launches the app with `XCUIApplication().launchArguments = ["--error-banner-fixture",
"short"|"long"]` (the DEBUG harness from round 1, rendering the REAL `ErrorBanner` in the
production top-overlay stack over the signed-out screen) and then:

1. `app.buttons["error-banner-dismiss"].waitForExistence(timeout: 30)` — the control is
   addressable by its accessibility identifier.
2. `dismiss.label == "Dismiss error"` — the runtime accessibility label VoiceOver reads
   (this is the first *runtime* proof of AC1's label, not a source pin).
3. `dismiss.frame.width >= 44` and `dismiss.frame.height >= 44` — the effective target the
   assistive layer sees, measured on the real screen.
4. `dismiss.isHittable` — no decorative layer intercepts the close target (AC6's runtime
   half).
5. `app.staticTexts["error-banner-message"].exists`; for the long fixture also
   `message.frame.height >= 60` — the rendered element is genuinely wrapped on screen.
6. `dismiss.tap()` then `dismiss.waitForNonExistence(timeout: 10)` **and**
   `XCTAssertFalse(message.exists)` — the banner and its message leave the screen.
