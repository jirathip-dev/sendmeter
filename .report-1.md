## Deliberate decisions / judgement calls

1. **Which terminal paths keep ending the gauge session.** Only the protocol's own user-initiated end
   (`endSession`, `endAndSavePartial`, i.e. Done / End / Stop) changed to `endGuidedProtocolOnly()`.
   `preserveInterruption` (disconnect) and the pause-save-failure terminal keep
   `finishGaugeSession()` because the issue names the disconnect ("disconnect during a guided run
   still ends via the guided-owned path") and a failed durable save is an error terminal, and
   `teardown()` (Force-tab disappearance / account transition) keeps it because that is the
   owner-lifecycle/account-teardown path (#628) that also runs for auth revocation. Consequence,
   disclosed: leaving the Force tab while a guided run is still active still ends the session, exactly
   as before this change (the completion path never reaches teardown because finishing clears the
   guided owner) — i.e. the issue's "explicit end / disconnect / account teardown" list is honoured
   for protocol completion, and the tab-switch teardown keeps its pre-existing semantics rather than
   silently changing in a second, unnamed direction.
2. **The completion action reads `Done` (not `Finish`)**, per #941's wording: the rep recordings were
   already durably queued when each stage advanced, so "Finish to save" would be false, and the panel
   caption names the Force tab's Finish pill as the explicit gauge-session end. The top-bar label
   stays `End` — #940 says it "may" change, and `ForceMotionWiringTests` (from #899) pins the literal
   `Button("End", action: endSession)` as "the single explicit save-and-exit".
3. **Completion cue = `.success`**: #940 asks for a `Haptics.shared` success cue, so the session's
   completion transition uses it instead of the `.complete` stage-transition rhythm. The Core rhythm
   row (`GuidedTransitionHaptics.cue(entering: .complete)`) is untouched and still pinned by
   `HapticsTests` for the stage-transition vocabulary.
4. **Accessibility:** the completion panel is deliberately NOT collapsed with
   `.accessibilityElement(children: .combine)` — that would swallow the Done button's action. Stage
   banners keep their existing combine/label/value chain verbatim.
5. **`GuidedProtocolActivityManager.swift` was NOT changed** (one of the brief's conditional files).
   Verified by reading it: the Live Activity is *protocol*-scoped — started in
   `GuidedForceProtocolSession.begin()` for the run, and ended by `claimTerminal()` →
   `model.guidedActivity.end(immediate: true)` on every guided terminal (Done, End, Stop, disconnect,
   teardown), with `reconcileOrphans()` sweeping anything that survived a force-quit. The gauge
   session has no Live Activity of its own, so keeping the session alive cannot leave a protocol-scoped
   card behind.
