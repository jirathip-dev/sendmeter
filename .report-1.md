The fix, in the `GuidedForceProtocolView` cover:

1. The background fills moved from inside
   `TimelineView → GeometryReader → ZStack` to the **root of the cover content**,
   outside `GeometryReader`: `.background { Color(systemGroupedBackground);
   accent.opacity(0.14) }.ignoresSafeArea()`; the presentation/accent are now computed
   in the `TimelineView` closure so the tint layer keeps its phase animation.
2. `protocolContent` now renders **one `ScrollView` for both layout branches**
   (content `minHeight: geometry.size.height`, chart height unchanged per branch), so a
   layout whose estimate says "fits" but whose real content overflows stays reachable.
   `GuidedForceLayout`/`GuidedForceFullscreenPresentation` (Core) are untouched — Core is
   outside this lane's fence.

### Why (measured, not guessed)

`GeometryReader` inside the cover reported `frame=(0.0, 62.0, 402.0, 778.0)`,
`insets=(top: 62, bottom: 34)` (iPhone 17 Pro), and `GuidedForceLayout` resolved
`fits=true, viewport=778, essential=674.04`. Consequences at 74212ec:

- the `.ignoresSafeArea()` fills nested 2 levels deep did **not** expand: the cover's
  container showed through as a **200 px = 66.7 pt band** above the content — white
  `(255,255,255)` in light mode, **black `(0,0,0)` in dark mode** (the device report's
  "solid black band");
- the fitting branch had **no scroll container at all**, so the real content (measured
  taller than the 778 pt viewport: the pre-fix capture ends mid-chart-card at the screen
  edge with the controls row below the screen) could not be scrolled into view.

Both numbers are reproducible from the committed fixture (see "Reproduce").

## Reproduce

```bash
xcrun simctl create "iphone17pro-sendmeter" \
  com.apple.CoreSimulator.SimDeviceType.iPhone-17-Pro com.apple.CoreSimulator.SimRuntime.iOS-26-5
xcrun simctl boot <udid>
xcodebuild -project native/SendmeterNative/SendmeterNative.xcodeproj -scheme SendmeterNative \
  -configuration Debug -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
xcrun simctl install <udid> <…>/Sendmeter.app
xcrun simctl launch <udid> com.jirathip.sendlog.native --guided-force-fixture=rest   # or =work
xcrun simctl io <udid> screenshot out.png
xcrun simctl launch <udid> com.jirathip.sendlog.native --guided-force-fixture-scrolled   # AC7
```

The fixture is `#if DEBUG`-only and launch-argument gated
(`GuidedForceFixtureView` + `GuidedForceFixtureCover` + `GuidedForceFixtureScroll` in
`ForceView.swift`, branch in `SendmeterNativeApp.swift`); it renders the real cover and
creates no network client, no auth change, no production data. Note for a re-run on a
fresh simulator: a launch can race a system relaunch of the app and silently drop the
launch arguments (login screen instead of the cover) — re-launch, or check that the top
row is the app's tint rather than the plain background.
