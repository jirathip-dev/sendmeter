## Deviations (owner's call, not invented)

1. **Watch tertiary text is lighter than the approved Watch status capture.** In "0–100" and "Fresh from iPhone", the
   brightest glyph pixels are about `(154,155,168)` after and `(99,100,110)` approved. The code is the prototype's
   unchanged: `WatchPalette.textTertiary` = `SendmeterPalette.textTertiary` dark `#9A9BA8`, the value the approved
   `tokens.md` lists, and `StatusView` is byte-identical to `fc1d8ada`. A full-strength `#9A9BA8` glyph is exactly
   `(154,155,168)`, so this branch renders the approved token. The approved Watch PNG shows a dimmer grey that no token
   in the approved sources produces. I left it as the approved token, which is AA at 7.09:1 on canvas.
2. **Workout, History, Settings and the sheets keep `systemGroupedBackground`.** The approved round changed only the
   Dashboard and Force backgrounds (B1). The other tabs' edges came with F5 (`.sendmeterTabBarEdge`, slice 3).
