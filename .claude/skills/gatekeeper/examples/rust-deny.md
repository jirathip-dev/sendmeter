# rust/deny: what a failure looks like

Each case is one change on the pack's fixture repo. `gatekeeper selftest` runs every case and fails unless the gate fails on it printing the line shown, so these examples cannot go stale.

## licence-outside-list

Writes `deny.toml`:

```
[advisories]
yanked = "deny"

[licenses]
allow = ["MIT", "GPL-3.0-only"]

[bans]
multiple-versions = "deny"
wildcards = "deny"

[sources]
unknown-registry = "deny"
unknown-git = "deny"
```

The gate fails and its log prints `licence GPL-3.0-only is outside`.

Fix: deny what the floor denies, pin the dependency to a version, or drop the crate whose licence is outside the list. Rerun: `./.gatekeeper/run check --gate rust/deny`
