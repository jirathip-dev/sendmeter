## F2 — the production default is witnessed, and the witness runs in CI

**Mechanism.** The bare-closure default was replaced by a value,
`PersistedFailureSink` (`Sources/Core/PersistedFailureLog.swift`):

```swift
public struct PersistedFailureSink {
    private let emit: @MainActor (PersistedFailureLine) -> Void
    public let isProduction: Bool
    public init(_ emit: @escaping @MainActor (PersistedFailureLine) -> Void,
                isProduction: Bool = false) { … }
    public static let production = PersistedFailureSink(PersistedFailureLog.emit,
                                                        isProduction: true)
    @MainActor public func callAsFunction(_ line: PersistedFailureLine) { emit(line) }
}
```

`AppModel.persistedFailureSink` and `WeatherService.persistedFailureSink` both
default to `.production`. A test-supplied capture is built with the default
`false`, so it cannot masquerade as the production binding.

**Witnesses (two, both CI-run):**

   (app-target suite) — builds a real `AppModel` **without substituting the
   sink** and asserts `model.persistedFailureSink.isProduction`; the F2 mutation
   below flips this RED.
2. `PersistedFailureLogTests.testProductionSinkReportsItselfAndStubsDoNot`
   (host suite) — asserts `.production` identifies as production and that both a
   capture and a no-op do **not**; this catches a mutation of the
